### 1.2 Vì sao dùng hai số phiên bản song song

`version.py` có `major / minor / patch` — các số này **phải giữ nguyên theo Godot (4.8)** vì engine dùng chúng để:
- kiểm tra tương thích GDExtension (`core/extension/gdextension_library_loader.cpp:348-379` so sánh với `compatibility_minimum` trong file `.gdextension`);
- ghi feature tag phiên bản vào `project.godot` và cảnh báo khi mở project khác phiên bản;
- đặt tên thư mục export templates (`GODOT_VERSION_FULL_CONFIG`).

Nếu đổi thành `0.1`, mọi GDExtension hiện có (godot-cpp, godot-rust, plugin cộng đồng) sẽ bị từ chối nạp. Vì vậy Bamboo có **phiên bản sản phẩm riêng** đặt cạnh phiên bản Godot gốc.

### 1.3 Cách đã cài đặt trong code

| File | Thay đổi |
| :--- | :--- |
| `version.py` | Thêm `bamboo_major = 0`, `bamboo_minor = 1`, `bamboo_patch = 0`, `bamboo_prerelease = "alpha.1"`, `bamboo_codename = "Sprout"` |
| `methods.py` | `get_version_info()` đọc các trường trên, tạo `bamboo_string` (`0.1.0-alpha.1`) |
| `core/core_builders.py` | Sinh macro `BAMBOO_VERSION_MAJOR/MINOR/PATCH/PRERELEASE/CODENAME/STRING` vào `core/version_generated.gen.h` |
| `core/version.h` | Thêm `BAMBOO_VERSION_FULL_BUILD`; `GODOT_VERSION_FULL_NAME` = `"<tên engine> v<bamboo> (Godot <base>)"` → tự áp dụng cho editor log, crash handler (macOS/Windows/Linux), glTF generator, GDExtension version string |
| `main/main.cpp` | `print_header()` in phiên bản Bamboo + Godot base |
| `editor/gui/editor_version_button.cpp` | Nút phiên bản ở thanh dưới editor + nút copy hiển thị phiên bản Bamboo |
| `core/config/engine.cpp` | `Engine.get_version_info()` thêm khóa `bamboo_major`, `bamboo_minor`, `bamboo_patch`, `bamboo_prerelease`, `bamboo_codename`, `bamboo_string` (các khóa cũ giữ nguyên) |

Giữ nguyên có chủ đích: `--version` vẫn in phiên bản Godot base (định dạng máy đọc được, dùng bởi script/CI); các khóa `major/minor/patch` của `Engine.get_version_info()` vẫn là của Godot.

### 1.4 Chính sách đánh số

- **SemVer** `MAJOR.MINOR.PATCH[-PRERELEASE]`:
  - `0.x` — trước khi ổn định API (đến hết 2027). `1.0.0` = Bamboo 1.0 LTS (Q4/2027).
  - **MINOR** tăng mỗi quý theo roadmap; **PATCH** cho bản sửa lỗi.
  - Prerelease: `alpha.N` (tính năng chưa đóng băng) → `beta.N` (feature freeze) → `rc.N` (ứng viên phát hành) → bản chính thức (bỏ hậu tố).
- **Codename theo dòng MINOR**: 0.1 *Sprout* (Măng) → các dòng sau đặt theo giai đoạn phát triển của tre (đề xuất: 0.2 *Shoot*, 0.3 *Culm*, 0.4 *Node*, 1.0 *Grove*).
- **Đổi phiên bản**: chỉ sửa các trường `bamboo_*` trong `version.py` → build lại. Không sửa `major/minor/patch` trừ khi rebase lên Godot minor mới.
- **`BUILD_NAME`**: CI chính thức đặt `BUILD_NAME=bamboo` (không dùng `official` — giá trị này kích hoạt một số hành vi riêng của bản Godot chính thức, vd. bundle id macOS).

## 7. Checklist phát hành (áp dụng cho mọi bản `alpha/beta/rc/stable`)

1. Cập nhật `bamboo_*` trong `version.py`; commit với thông điệp `Bump Bamboo version to X`.
2. CI xanh trên mọi nền tảng; benchmark không giảm quá 5% so với bản trước (trừ khi có giải thích).
3. Smoke test: mở Project Manager, tạo project, chạy scene 2D + 3D, export Windows/macOS/Linux/Android.
4. Kiểm tra chuỗi phiên bản ở: log khởi động, About, thanh dưới editor, `Engine.get_version_info()["bamboo_string"]`, crash log.
5. Gắn tag `bamboo-vX`, đính kèm editor + `.tpz` templates + release notes.
6. Cập nhật bảng phiên bản ở mục 1.4.
